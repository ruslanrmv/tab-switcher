# Tab Switcher Personal

Локальное расширение Chrome и программа macOS для переключения вкладок с помощью Control + Tab. Карусель показывает превью посещённых вкладок и следует за выбором.

Вкладку можно переименовать сочетанием **Option + Shift + N** или через её контекстное меню. Имя сохраняется в текущей сессии Chrome до перехода на другой адрес. Исходное имя можно вернуть кнопкой со стрелкой в редакторе.

## Установка

Скачайте архив `Tab-Switcher-Personal-macOS.zip` из репозитория, распакуйте его и запустите `Установить Tab Switcher.app`. Следуйте указаниям установщика: разрешите доступ macOS для сочетаний клавиш и загрузите указанную папку Extension на странице расширений Chrome. Не перемещайте установленную папку расширения. Интернет-магазин Chrome не требуется.

Комплект подписан локально и не нотариально заверен Apple. Автоматических обновлений нет; следующая версия устанавливается отдельно. Поддерживается macOS 14 и новее с Apple Silicon или Intel.

Сборка для превью системных страниц находится в разработке и требует отдельного разрешения macOS на запись экрана. Снимки веб-страниц и имена вкладок хранятся локально в сессии браузера.

## Сборка

На Mac с инструментами Xcode задайте `TAB_SWITCHER_TEMPLATE` как путь к существующему комплекту Tab Switcher Personal с встроенной библиотекой Sparkle и запустите `scripts/build-installer.sh`. Скрипт создаёт архив в `dist/` либо по пути `TAB_SWITCHER_PACKAGE_OUTPUT`. Пакет использует стабильный идентификатор расширения и настраивает связь с программой локально.
