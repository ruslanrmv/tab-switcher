Tab Switcher Personal для macOS и Google Chrome

1. Распакуйте архив полностью, затем откройте «Установить.command».
2. При первом открытии macOS может потребовать разрешить запуск неподписанного комплекта через «Конфиденциальность и безопасность». Программа требует доступ «Универсальный доступ» для Control+Tab; разрешите его в настройках macOS.
3. Установщик откроет папку Extension и страницу расширений Chrome. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку Extension. Её нельзя удалять или перемещать после подключения.
4. Перезагрузите расширение после выдачи разрешения macOS. Удерживайте Control и нажимайте Tab.

Связь программы с расширением настраивается установщиком. Интернет-магазин Chrome не нужен. Установка не заменяет существующую версию: при обнаружении прежней конфигурации установщик остановится. Сборка локально подписана, не нотариально заверена Apple; автообновлений этой персональной сборки нет. Распространяйте только тем, кто доверяет этому комплекту. macOS 14 или новее, Apple Silicon и Intel.
