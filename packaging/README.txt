Tab Switcher Personal для macOS и Google Chrome

1. Распакуйте архив полностью и откройте «Установить Tab Switcher.app».
2. Следуйте подсказкам установщика: разрешите программе доступ в macOS и один раз выберите папку Extension на странице расширений Chrome. Установщик скопирует путь к этой папке, чтобы его можно было вставить в окно выбора.
3. После завершения удерживайте Control и нажимайте Tab в Chrome. Не удаляйте и не перемещайте установленную папку Extension.

При первом открытии macOS может потребовать разрешить запуск неподписанного комплекта через «Конфиденциальность и безопасность». Программа требует доступ «Универсальный доступ» для Control+Tab. После прерывания можно снова открыть установщик: он продолжит установку, если обнаружит тот же комплект и правильные настройки.

Связь программы с расширением настраивается установщиком. Интернет-магазин Chrome не нужен. Если обнаружена другая версия или конфигурация, установщик остановится, чтобы их не перезаписать. Сборка локально подписана, не нотариально заверена Apple; автообновлений этой персональной сборки нет. Распространяйте только тем, кто доверяет этому комплекту. macOS 14 или новее, Apple Silicon и Intel.
